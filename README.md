# The Spice Studio — Static Website

A responsive, single-page restaurant lead-generation website built with plain HTML, CSS and JavaScript.

## Run locally
- Open this folder in VS Code.
- Recommended: run with the Live Server extension, or use `python -m http.server 8000` from this folder.
- Visit `http://localhost:8000`.

## Deploy
Upload the contents of this folder (not the enclosing ZIP) to Netlify, Vercel static hosting, GitHub Pages, or any standard web host. No build step is required.

## Before publishing
1. Replace `hello@thespicestudio.example` with the restaurant's real business email in `index.html`.
2. Replace Facebook and Instagram placeholder destinations with the restaurant's official profiles.
3. Test the WhatsApp links and all three forms on a phone. Forms open WhatsApp with a pre-filled message; the visitor must press Send. No form data is stored by this static site.
4. Confirm that the video plays on the target hosting service and check the final address/map pin.
5. Add any further supplied food/gallery assets if available.

## Assets
All supplied assets are included in `assets/`. The hero video is locally hosted and muted/looping. The website intentionally contains no operating hours, prices, or downloadable menu.
